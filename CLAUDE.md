# 21 DC Challenge Dashboard — Contexto del Proyecto

Este proyecto es el 21 DC Challenge Dashboard para Strong Standard Coaching.
Lee los archivos en la carpeta /context antes de hacer cualquier cosa.
El archivo más importante es el Proyecto D Prompt — define el scope completo, las 5 vistas, el stack técnico y el orden de construcción.
El Master Decision Log v2 tiene todas las decisiones tomadas en los Proyectos A, B y C.
Stack: HTML + Google Apps Script + GHL API directa.
Empieza siempre por confirmar que leíste el contexto antes de proponer cualquier acción.

La fuente de verdad de cómo funciona el dashboard es `DASHBOARD-SYSTEM.md` (documento vivo). El registro de cambios es `DECISION-LOG.md`.

---

## ⚠️ REGLA DE DOCUMENTACIÓN (obligatoria en cada cambio al dashboard)

Siempre que se haga cualquier cambio al dashboard (frontend `index.html` o backend `.gs`):

1. Hacer `git pull` antes de empezar.
2. Aplicar el cambio.
3. Actualizar `DASHBOARD-SYSTEM.md` para reflejar el nuevo comportamiento, y actualizar su fecha de "Última actualización".
4. Agregar una entrada a `DECISION-LOG.md` con la fecha, qué se cambió y por qué.
5. Hacer `git push`.

**Un cambio no se considera terminado hasta que la documentación esté actualizada y subida.**
