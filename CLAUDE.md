# 21 DC Challenge Dashboard — Contexto del Proyecto

Este proyecto es el 21 DC Challenge Dashboard para Strong Standard Coaching.
Lee los archivos en la carpeta /context antes de hacer cualquier cosa.
El archivo más importante es el Proyecto D Prompt — define el scope completo, las 5 vistas, el stack técnico y el orden de construcción.
El Master Decision Log v2 tiene todas las decisiones tomadas en los Proyectos A, B y C.
Stack: HTML + Google Apps Script + GHL API directa.
Empieza siempre por confirmar que leíste el contexto antes de proponer cualquier acción.
